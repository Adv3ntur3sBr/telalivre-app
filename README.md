# TelaLivre para Windows

Instaladores do **TelaLivre**: compartilhamento de tela grátis, sem conta, com a placa de vídeo.

**[⬇ Baixar TelaLivre-Setup.exe](https://github.com/Adv3ntur3sBr/telalivre-app/releases/latest/download/TelaLivre-Setup.exe)** · ou use pelo navegador: <https://telalivre-three.vercel.app>

- Transmissão codificada pela GPU (NVIDIA NVENC, Intel Quick Sync, AMD AMF)
- Seletor de telas e janelas com miniaturas ao vivo
- Áudio do PC inteiro + chat de voz independente da tela
- Mesmas salas do site; o app se atualiza junto com o site

Windows 10 e 11, 64 bits. Se aparecer **"O Windows protegeu o computador"**, clique em **Mais informações → Executar assim mesmo** (o app não tem assinatura digital paga).

Este repositório guarda só os instaladores (aba *Releases*).
